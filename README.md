# বাজার দর | BazarDor

**BazarDor** is a marketplace price guide that helps users explore current prices of everyday products, compare market prices, and see which prices have risen or fallen.

## Technologies Used

- **Next.js 16** — React framework and application routing
- **React 19** — User interface
- **TypeScript** — Type-safe JavaScript
- **Tailwind CSS 4** — Styling and responsive layouts
- **Better Auth** — User authentication
- **MongoDB** — Database support for authentication
- **HeroUI** — UI components
- **BazarDor Products API** — Product, category, and price data

## Key Features

1. **Browse product categories**  
   Explore products grouped by category.

2. **View product details**  
   See product information, current prices, and market-by-market price ranges.

3. **Track price changes**  
   Quickly find products whose prices have increased or decreased.

4. **Compare market prices**  
   Review minimum and maximum prices across markets.

5. **Create and manage an account**  
   Sign up, sign in, view your profile, update your name, and sign out.
